# Calculadora sencilla

Este repositorio contiene una calculadora muy simple escrita en Python.

Cómo ejecutar (Windows PowerShell):

```powershell
python .\main.py
```

Sigue las instrucciones en pantalla para elegir una operación y proporcionar números.

Operaciones soportadas: sumar, restar, multiplicar, dividir y potencia.

¡Disfruta!
